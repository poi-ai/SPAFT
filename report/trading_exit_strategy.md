# RPAデイトレ 出口・売り戦略レポート

`csv/statistics/` 配下の統計18ファイルおよび `csv/indicator/*_with_indicators.csv` (36,733行) から、**下落しやすいシグナル** と **既存ロングポジションの利確/損切りタイミング** を調査した結果をまとめる。

> **位置付け**: 兄弟ファイル [`trading_strategy_recommendations.md`](trading_strategy_recommendations.md) は **エントリー（買い）** に焦点を当てているため、本レポートは **エグジット（売り）** および **空売りエントリー** に特化する。

## 集計対象

- 期間: 2026-04-XX 〜 2026-04-XX（11営業日）
- 銘柄: 16銘柄
- 足: 1分足
- リーク済みカラム（`pl_*` 系）は除外

## 1. 下落しやすいシグナルの偏り

### 1.1 売り側エッジは買い側より構造的に弱い（最重要前提）

統計CSV全体の傾向として、買われすぎ（overbought）からの反落は売られすぎ（oversold）からの反発より **明らかに弱い**。

| 比較 | 売られすぎ（買いシグナル） | 買われすぎ（売りシグナル） |
|---|---|---|
| RSI(9) 極値 | < 10: 勝率 **61.1%** (n=773, nbar=30) | ≥ 90: rise_rate **49.9%** (n=935, 反落エッジ無し) |
| BB 2σ ブレイク | 下抜け: 勝率 52-53% (nbar=10〜30) | 上抜け: fall_rate 51-53% (nbar=5〜15のみ) |
| 最強組合せ | RSI(9)≤10 単独 EV +0.157% | BB>u2σ AND RSI≥80 AND RCI≥80 EV +0.109% (短時間のみ) |

→ 期間中（2026-04）が **反発相場・上昇トレンド** だった可能性が高い。売り側エッジは:
- **保有時間が短い場合のみ** 機能（5-10分）
- **15-30分以上保有すると逆に上昇に転じる**（モメンタム継続）
- **日次安定性が低い**（後述 1.4）

## 2. 推奨戦略案（売り・出口）

### 戦略X: BB+RSI+RCI 3重AND による短期ショート（メイン売り戦略）

| 項目 | 内容 |
|---|---|
| 売りシグナル | `close > bb_1min_20piece_upper_2sigma` **かつ** `rsi_1min_9piece ≥ 80` **かつ** `rci_1min_26piece ≥ 80` → 信用新規売 |
| 保有時間 | **10分（=10本）固定**（15分以上は機能低下、30分でゼロ） |
| 期待勝率 | **62.0%** (n=205) |
| 期待値 | rate_mean -0.109% × 建玉（=ショートの利益）、利幅中央 +21円 vs 損失中央 -11円 (R/R≒1.9) |
| エントリーフィルタ | `bb_1min_20piece_width / close_price ≥ 0.0036`（ボラ十分）|
| 損切り | 保有中 +0.5% 逆行（=close が更に上昇）|
| 失効条件 | 大引け15分前(15:15)以降は新規禁止 |

**注意**: 日次 fall_rate std=0.226 と不安定。直近30シグナルで fall_rate < 50% なら停止。  
**リスク**: 信用売り（空売り）は逆日歩・規制銘柄の制約あり。事前に対象銘柄の信用区分を確認。

### 戦略Y: 既存ロングポジションの利確（プロフィットターゲット）

買い戦略（`trading_strategy_recommendations.md` 戦略A〜D）でロングを建てた後、以下のいずれかの条件でロスを30分時間ストップ前に **早期手仕舞い**:

| 利確トリガー | 根拠 |
|---|---|
| `close ≥ bb_1min_20piece_upper_2sigma` | BB上抜けはその後5-15分で fall_rate 0.52 → 反落確率高い |
| `rsi_1min_9piece ≥ 80` かつ `rci_1min_26piece ≥ 80` | 高値圏ダブル達成 (戦略Xの2/3条件) |
| 含み益が `+amount_std × 1.5` を超えた | 銘柄別 std による伸び切り判定 |
| 保有 15 本（=戦略指定の半分）経過 で含み益 +0.1% 以上 | 早期確定で R/R 確保 |

複数ヒット時は最初のものでクローズ。**部分利確（半分クローズ）は API 上の建玉管理が複雑になるため非推奨**。1建玉 = 1判定でシンプル化。

### 戦略Z: 既存ロングポジションの損切り（ストップロス）

| 損切りトリガー | 値 |
|---|---|
| 含み損が建値比 -0.7% (=戦略B/C の場合) / -0.5% (=戦略A の場合) | 統計のp10下振れ準拠 |
| 保有中に `rsi_1min_9piece` が 80 を一度超え、その後 50 を下回る | モメンタム反転 → 早期撤退 |
| `close < bb_1min_20piece_lower_3sigma` | 反発トレンド崩壊 |
| 保有時間が指定 nbar の 1.5倍を超過 | 想定外の停滞 → 損益関係なくクローズ |

時間ストップ + 価格ストップ + モメンタムストップの**3条件OR**で運用。**含み損中に追加買い（ナンピン）は禁止**。

### 戦略W（補助）: BB 3σ 上抜けでの短時間ショート

| 項目 | 内容 |
|---|---|
| 売りシグナル | `close > bb_1min_20piece_upper_3sigma` |
| 保有時間 | 5-10分 |
| 期待勝率 | 54-60%（n=85〜109、希少）|
| 期待値 | -0.05〜-0.12% / 建玉 |
| 注意 | サンプル100件以下 / 1日 0〜数件しか発火しない |

戦略Xと**OR条件**で発動。3σ上抜けは強い反落シグナルだが希少なので、戦略Xを補完する位置付け。

### 戦略 NG: 売り側で避けるべきシグナル

| シグナル | 理由 |
|---|---|
| 単独 RSI(9)≥80 | rise_rate 0.49 ≒ fall_rate 0.49（無相関）|
| 単独 RCI(26)≥80 | 同上、エッジ僅少 |
| **PSY≥80 で売り** | rise_rate 0.53 と **逆に上昇** |
| nbar=15以上のショート | 上昇相場由来のモメンタム継続で fall_rate が低下 |
| MA ゴールデンクロスで売り単独 | 利幅 -0.01% と薄すぎ、コスト負け |
| 価格 > MA で売り単独 | 反落バイアス僅か (fall_rate 0.50) |

## 3. 売り戦略の RPA 実装上の留意点

### 3.1 信用売りの制約

- **デイトレ信用 (一般信用 / 制度信用) で売り注文を行う場合、銘柄が空売り可能区分か事前確認** (KabuStation API `/symbol/{code}` の `MarginType` 等)
- 一部銘柄は売り禁止 / 空売り規制 (50単位制限) あり
- 逆日歩発生のリスク (デイトレ信用は当日返済なので原則回避できるが、約定タイミングで翌日越し → 逆日歩発生に注意)

### 3.2 売り戦略の運用優先度

買い戦略（A/B/C）と売り戦略（X）が同時発火することは構造上ほぼない（買われすぎと売られすぎの同時発火不可）。
ただし**異なる銘柄で同時発火**した場合は:

1. 期待値の高い方を優先
2. 銘柄当たり同時建玉は1まで
3. 売り戦略はサンプル不安定性が大きいため、**全建玉のうち売りは最大30%まで**に制限

### 3.3 3.1〜3.5 のうち買い戦略と共通の項目

`trading_strategy_recommendations.md` 第3章を参照。エントリータイミング（00〜02秒判定）、レート制限、リスクパリティ建玉サイジング、KabuStation 制約は同様。

### 3.4 売り戦略固有の停止条件

- **直近30シグナルで fall_rate < 0.50** で戦略X停止
- **5営業日連続で売り戦略が日次マイナス** で全売り戦略停止 → 翌週まで
- buy/sell の月次PLが両方マイナスなら全戦略停止 → 統計再集計

### 3.5 当日決済（デイトレ信用）必須

- 戦略 X/W はすべて **当日中に決済**（デイトレ信用の前提）
- 大引け5分前(15:25)に未決済建玉があれば **無条件で成行決済**
- 寄り越し・引け越しは禁止（リスク管理上）

### 重要な所感

- **売り側エッジは買い側より構造的に弱い**: 期間中（2026-04）が反発相場だったのが主因の可能性。**11日のサンプルでは売り戦略は確証が弱い**
- **必須実装は戦略Y/Z（既存ロングの出口管理）**: 売りエントリー（戦略X）より、買いポジションの利確/損切りロジックの方が優先度が高い
- **戦略X は条件付き運用**: サンプル数(205件) と日次不安定性 (std=0.226) を考慮し、買い戦略と同等の建玉量で動かさず、**全建玉の30%上限**を設ける
- **保有時間が買い側より短い**: 買いは15-30分、売りは5-10分が最適
- **R/R比は良好**: 3重ANDの利益/損失比は約1.9倍と非対称に有利
- **長期データでの再検証必須**: 3ヶ月以上のデータで売り側エッジが消えるなら、「買い専用 + 出口管理のみ」の運用に切り替える
