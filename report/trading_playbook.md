[`trading_strategy_recommendations.md`](trading_strategy_recommendations.md)（エントリー）と [`trading_exit_strategy.md`](trading_exit_strategy.md)（エグジット）の内容を、**RPA 実装で直接参照する形** に統合したクイックリファレンス。

> **読み方**: シグナルが発火したら表の通りに発注 → 「保有時間」or「早期売却条件のいずれか」が来たら即決済。考える要素は最小化、迷ったら時間ストップで決済。

## 2. 早期売却（時間切れ前のエグジット）判定ルール

エントリー後、保有中は **毎分1回** 以下を判定する。**最初に該当した条件で即決済** する（複数判定はしない、シンプル化優先）。

### 2.1 利確（プロフィットターゲット） — 含み益の取り逃し防止

| # | 条件 | 適用戦略 | 根拠 |
|---|---|---|---|
| **TP-1** | `close ≥ bb_1min_20piece_upper_2sigma` (建玉が買いの場合) | A/B/C/D/E | BB上抜けは5-15分で fall_rate 0.52 → 反落確率高く、ここで利確が筋 |
| **TP-2** | `rsi_1min_9piece ≥ 80` **かつ** `rci_1min_26piece ≥ 80` (買い建玉) | A/B/C/D/E | 戦略X の 2/3 条件達成 = 反転シグナル |
| **TP-3** | 含み益が 銘柄別 `amount_std × 1.5` 以上 | A/B/C/D/E | 統計的「伸び切り」判定 |
| **TP-4** | 保有時間が指定の **半分** に達し、かつ含み益 `≥ +0.1%` | A/B/C/D/E | 早期確定で R/R 確保 |
| **TP-5** | 含み益が `+amount_median × 3` 以上 | D（利幅薄い戦略） | 1建玉あたりの利益確定優先 |
| **TP-S1** | `close ≤ bb_1min_20piece_lower_2sigma` (建玉が売りの場合) | X/W | 売り側のミラー版 |
| **TP-S2** | `rsi_1min_9piece ≤ 20` **かつ** `rci_1min_26piece ≤ -80` (売り建玉) | X/W | 戦略B/A の条件達成 = 反転 |

### 2.2 損切り（ストップロス） — 想定外の逆行を限定

| # | 条件 | 適用戦略 | 根拠 |
|---|---|---|---|
| **SL-1** | 含み損が建値比 **-0.7%** 以下 | B/C（高期待値だが下振れあり） | RSI(9)≤10 の p10 下振れ -0.56% に -0.14% バッファ |
| **SL-2** | 含み損が建値比 **-0.5%** 以下 | A/D/E（戦略Eは下振れ管理重視） | 戦略E p10 下振れ -0.50% に合わせる |
| **SL-3** | 含み損が建値比 **+0.5%** 以上 (=ショート逆行) | X/W | 売り側は短時間決済前提 |
| **SL-4** | `close < bb_1min_20piece_lower_3sigma` | A/B/C/D/E | 反発トレンド崩壊 → 即撤退 |
| **SL-5** | `close > bb_1min_20piece_upper_3sigma` | X/W | ショート逆行の3σ → 即撤退 |
| **SL-6** | 保有時間が指定 nbar の **1.5倍** を超過してもポジション維持中（理論上来ない、保険）| 全戦略 | 想定外停滞 → 損益不問でクローズ |

### 2.3 モメンタムストップ — 反転兆候での早期撤退

| # | 条件 | 適用戦略 | 根拠 |
|---|---|---|---|
| **MS-1** | 保有中に `rsi_1min_9piece` が **80 を一度超え**、その後 **50 を下回った** | A/B/C/D/E | 上昇モメンタム反転の典型 |
| **MS-2** | 保有中に `rsi_1min_9piece` が **20 を一度下回り**、その後 **50 を上回った** | X/W | 下落モメンタム反転（ショート逃げ） |
| **MS-3** | 保有中の `rci_1min_26piece` が建玉開始時から **+50 以上反転** | A/E | RCI由来エントリーは RCI 反転を最優先で見る |

### 2.4 時間ストップ（最終手段）

上記いずれにも該当しないまま **エントリー時の指定保有時間（10/15/30分）が経過** したら、損益不問で **成行決済**。

## 4. 優先順位ルール（複数シグナル同時発火時）

### 4.1 同一銘柄で複数戦略が発火

買いシグナルは互いに重複しやすい（例: RSI<10 と RCI<-80 と PSY<10 が同時）。
**優先度: B > C > E > A > D**（期待勝率順）。最も期待勝率の高い戦略のパラメータを採用。

### 4.2 異なる銘柄で同時発火

同時間帯に複数銘柄でシグナルが出る場合:

1. **発注API 5件/秒制限** に注意し、200ms 間隔で順次発注
2. 銘柄の **流動性（出来高）** が高い順に優先
3. 銘柄当たり同時建玉は **1まで**（既に建玉ありなら追加しない）

### 4.3 買いと売りが異なる銘柄で同時発火

買い戦略 A〜E と売り戦略 X/W が両方発火することは構造上ほぼ無い（市場全体が売られすぎ＋買われすぎを同時に示すケースは稀）。
万一発火した場合:
- **売り建玉が全建玉の30%未満** ならどちらも採用
- **売り建玉が30%以上** なら買い側のみ採用、売り側はスキップ

## 5. 全停止条件（サーキットブレーカー）

戦略の優位性が崩れたと判断する基準。**満たしたら当日中の新規エントリーを全停止**。

| # | 条件 | 対処 |
|---|---|---|
| **CB-1** | その日の累計実現損益が **-3%（建玉ベース）** に到達 | 当日全停止、翌営業日再開 |
| **CB-2** | 直近 30 シグナル（戦略B）の rise_rate < 50% | 戦略B のみ停止、戦略A/C/D/E は継続 |
| **CB-3** | 直近 30 シグナル（戦略X）の fall_rate < 50% | 戦略X 即停止 |
| **CB-4** | 5営業日連続で売り戦略が日次マイナス | 全売り戦略停止、翌週まで |
| **CB-5** | KabuStation API トークン無効化 | 全停止 → 再起動 → 再発注は禁止（保有のみ管理） |
| **CB-6** | WebSocket 切断（昼休み以外） | 復旧まで新規停止、保有は時間ストップで処理 |

     ↓

     ├─ TP系該当 → 成行決済 → ループ終了

## 8. まとめ — 一行で言うと

> **RSI(9)<10 で買って 30 分保有、ただし BB上抜け or RSI≥80&RCI≥80 or 半分時間で含み益+0.1% 達成なら早期利確、含み損 -0.7% で損切り。**

これが本プレイブックの核心。他の戦略 A/C/D/E/X/W は補助・代替・リスク調整用と位置付けて、まずは戦略B + 早期売却ロジックを実装するのが投資対効果最大。
